# 实验配液计算器使用指南

本指南对应 1.6.1。界面截图和文中数值均为合成演示数据，用于解释软件操作与公式，不是实验条件建议。

## 选择工作表

启动后，顶部提供“菌液配比”和“材料配制”两个入口。两张工作表的输入、结果与模板互相独立，切换不会清空本次数据。OD600–CFU 换算从菌液页右上角的按钮打开。

![菌液配比工作表](images/overview.png)

窗口较小时可滚动工作区、输入列表或结果表。表格列较多时可横向滚动；不需要缩小系统字体。

## 菌液配比

### 填写本次读数

1. 设置菌液数量，填写样品名称。
2. 填写已扣空白的本次 OD，以及测前稀释倍数。
3. 填写各组分所需的 OD 贡献比例。
4. 填写目标总 OD、最终体积和单位。
5. 选择配液流程，点击“计算配液量”。

| 字段 | 应填写的内容 |
| --- | --- |
| 测得初始 OD | 实际测得、已扣空白的 OD 读数 |
| 测定稀释倍数 | 原液直接测量填 1；测前稀释后填相应倍数 |
| OD 贡献比例 | 各菌液对最终混合液理论 OD 的相对贡献 |
| 混合液目标总 OD | 希望达到的理论混合 OD |
| 最终总体积 | 全部组分混合后的目标体积 |

程序使用“测得 OD × 测前稀释倍数”还原原液 OD。如果填写的读数已经还原过，应把倍数设为 1，避免重复乘倍数。用于同一配方的 OD 读数应采用一致的测量波长和空白处理。

### 选择流程

| 流程 | 操作含义 |
| --- | --- |
| 分别稀释后混合 | 每种菌液分别配成等体积，再将各管全部合并 |
| 原液直接混合 | 各原液取入同一管，统一补液至最终体积 |

两种流程可能得到相同的原液取液量，但分别稀释还受各管容量限制。程序按当前选择判断可行性，不会自动替换流程。出现不可行提示时，应核对原液 OD、比例和目标总 OD；只改变总体积通常不会改变浓度可行性。

配比只描述理论 OD 贡献，不表示 CFU 比例。计算结果中的体积显示三位小数，内部计算保留更高精度，显示数相加可能有微小舍入差异。

## 材料百分浓度配制

![材料百分浓度工作表](images/materials-percent.png)

1. 选择 w/w、w/v 或 v/v。
2. 填写最终总质量或最终总体积，并选单位。
3. 为每种材料填写名称与目标百分浓度。例如 20% 填 `20`。
4. 可填写溶剂或基质名称，留空时显示通用名称。
5. 点击“计算材料用量”，核对各组分用量和溶剂行。

| 口径 | 定义 | 软件输出 |
| --- | --- | --- |
| w/w | 组分质量 ÷ 最终配方总质量 × 100% | 各材料质量及补足总质量所需的溶剂质量 |
| w/v | 每 100 mL 最终配方中的材料克数 | 各材料质量，溶剂适量并定容至最终体积 |
| v/v | 液体组分加入体积 ÷ 最终配方体积 × 100% | 各液体材料体积，溶剂适量并定容至最终体积 |

合成计算示例：

| 输入 | 材料用量 | 溶剂处理 |
| --- | --- | --- |
| 20% w/w，最终 20 g | 4 g | 加入 16 g，补足总质量至 20 g |
| 20% w/v，最终 20 mL | 4 g | 加入适量，最终定容至 20 mL |
| 70% v/v，最终 10 mL | 7 mL | 混合后定容至 10 mL |

定容指所有组分混合后的最终体积，不是额外加入等于该体积的溶剂。液体混合前后的体积不保证简单相加，固体质量也不能直接当作体积，因此体积模式不输出由简单相减得到的精确补液量。

同一配方的所有组分采用同一浓度口径。当前软件对 w/w、v/v 的各组分百分数之和设定不超过 100% 的输入限制；w/v 的百分数是 g/100 mL，不据此限制为 100%。这些校验不证明材料能够溶解或实际能够配成目标状态。

## 材料摩尔浓度配制

![材料摩尔浓度工作表](images/materials-molar.png)

选择“摩尔浓度”后，填写最终总体积，为每种材料分别填写目标浓度、浓度单位、摩尔质量和摩尔质量单位，再选择称量结果单位。

| 类别 | 单位与含义 |
| --- | --- |
| M | mol/L |
| mM | 10⁻³ mol/L |
| μM | 10⁻⁶ mol/L |
| nM | 10⁻⁹ mol/L |
| g/mol、mg/mol | 摩尔质量，1 g/mol = 1000 mg/mol |
| g、mg、μg | 称量结果的质量单位 |

计算关系：

`称量质量(g) = 目标浓度(mol/L) × 最终体积(L) × 摩尔质量(g/mol)`

例如，目标浓度 10 μM、最终体积 20 mL、摩尔质量 500 g/mol，得到 0.1 mg，即 100 μg。将摩尔质量等价写为 500000 mg/mol，结果相同。该数值仅是公式校验；实际原料应使用其对应盐型、水合状态的摩尔质量。

每种材料可使用不同的摩尔浓度单位。切换口径会保留可编辑的输入，但不代表已经完成等效浓度换算。改变浓度、单位、摩尔质量或总量后，旧结果会失效。

## OD600–CFU 换算

![OD600–CFU 换算窗口](images/cfu.png)

本功能采用由用户提供系数的过原点线性模型，不包含截距。程序没有通用换算系数，也不会把菌液配比页的读数自动当作本次 OD600 输入。

1. 填写自行建立的校准系数 `k`，或调用已保存校准方案。
2. 选择换算方向，填写本次读数和测前稀释倍数 `D`。
3. 按需填写实测 OD600 的适用范围、菌株和测量条件。
4. 点击“换算浓度”，检查结果及范围提示。

| 方向 | 输入 | 计算与结果 |
| --- | --- | --- |
| OD600 → CFU/mL | 已扣空白的实际 OD600 读数 | 估算原液 CFU/mL = k × 实测 OD600 × D |
| CFU/mL → OD600 | 原液 CFU/mL | 原液等效 OD600 = CFU/mL ÷ k；预计实测 OD600 = 原液等效 OD600 ÷ D |

`k` 为每单位 OD600 对应的 CFU/mL。原液直测时 `D = 1`；若输入已经按稀释倍数还原过，不应再重复乘倍数。

校准范围对应实测或预计实测 OD600，不是还原后的原液等效 OD600。未填写范围时会显示相应提示；超出范围时会标记线性外推。校准关系应与菌株、仪器和测量条件匹配。结果属于估算，不替代平板计数；输入零得到模型零值也不能证明无菌。该功能不从混合菌总 OD 拆分各菌 CFU。

## 模板与本地数据

菌液模板、材料模板和 CFU 校准方案独立保存。填写名称后可保存新模板，调用后可更新已有模板；删除操作会要求确认。

| 文件 | 内容 |
| --- | --- |
| `templates.json` | 菌液配方及可选的本次初始 OD |
| `materials_templates.json` | 材料配方、浓度口径、单位和摩尔质量等字段 |
| `cfu_calibrations.json` | 校准系数、适用范围与条件，不含本轮读数 |

本地存储目录为 `%LOCALAPPDATA%\菌液配比计算器`。这个通用目录名沿用于旧版本兼容，不会因程序改名而迁移已有模板。

备份时先关闭程序，再复制所需文件；恢复时也先关闭程序，再将备份文件放回同一目录。公开发行包不携带个人模板、校准数据、实验结果或运行日志。未保存的本次输入不会自动保留到下一次启动。

菌液模板可不保存初始 OD，调用后重新填写本次读数；勾选“包含本次初始 OD”后才随模板保存。材料模板的总量或浓度暂未补齐时可先保存，计算前仍须填写必需字段；材料名称须填写。

## 复制、CSV 和快捷键

计算成功后，可复制结果表或导出 CSV。记录保留输入口径、单位及必要计算说明；CSV 使用 UTF-8 BOM，适合用 Excel 打开。

| 快捷键 | 当前工作表 | CFU 窗口 |
| --- | --- | --- |
| Ctrl + Enter | 执行当前计算 | 执行换算 |
| Ctrl + S | 保存或更新当前模板 | 保存或更新校准方案 |

修改输入后，旧结果会立即失效，复制和导出按钮禁用。请重新计算，再保存本次结果。

## 常见问题

**为什么出现“需重新计算”？** 输入、单位、口径或模板已经改变，当前结果不再对应当前输入。重新计算即可。

**为什么不能保存模板？** 先检查模板名称是否为空或重复。模板文件损坏或无法读取时，软件保留原文件并阻止覆盖；计算功能仍可使用。可先备份本地模板文件，再检查其格式。

**为什么 w/v 或 v/v 没有固定补水量？** 程序使用最终配方体积作为分母，不假定材料加入前后体积简单相加，所以给出适量和定容目标。

**g/mol 能否直接作为浓度？** 不能。它表示摩尔质量；目标浓度应填写 M、mM、μM 或 nM 等摩尔浓度单位。

**为什么换算结果显示外推？** 本次实测或预计实测 OD600 超出了保存方案填写的范围，不能将该结果视为已在该范围内完成校准。

## 源码运行与许可

安装 Python 3.11 或更新版本，以及系统 WebView2 Runtime。在源码目录执行：

```powershell
python -m pip install -r requirements.txt
python glass_app.py
```
